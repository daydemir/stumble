Every letter drifts with the same excursion magnitude, in its own direction. The headline uses the default options. Select it and copy: it's still one string. In devtools, document.getAnimations() shows one animation per letter, each on a plain <span>.

Reduce motion is on, so everything is still. Turn it off in your system settings and the letters start moving without a reload.
